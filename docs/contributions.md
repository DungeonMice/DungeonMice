# Contribución

Gracias por tu interés en contribuir al desarrollo del **backend de DungeonMice**.  
Este documento describe las reglas y buenas prácticas para mantener un flujo de trabajo claro, reproducible y sostenible dentro del proyecto.

---

## Filosofía del proyecto

DungeonMice es una herramienta académica orientada al **análisis reproducible de experimentos conductuales con roedores**.  
Por ello, cada contribución debe priorizar:

- Claridad del código.
- Reproducibilidad científica.
- Documentación suficiente.
- Simplicidad antes que complejidad innecesaria.

Si deseas colaborar con el proyecto puedes clonarlo y trabajar de forma indenpendiente realizando los clásicos ``pull request`` o puedes contactar con el equipo de Physics in Silico para formar parte del equipo principal.
